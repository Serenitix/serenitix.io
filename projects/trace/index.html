DARPA ERIS · Listing 7-26-3487

Awardable

TRACE

Software Understanding Assurance for Autonomous Cyber Analysts

Serenitix · Contact us about this listing

The problem

Autonomous cyber analysts are already in use. AI agents hunt vulnerabilities, triage malware, and reverse unknown binaries in real workflows. The open question is how much to trust what they report.

When an autonomous analyst reports "no findings," the report alone does not say whether the agent understood the software and found it clean, or never examined the parts that matter. That difference is a security difference: the interfaces, parsers, and authority paths an analyst fails to understand are where an adversary can still find an exploit.

Fuzzing and testing have coverage measures. Autonomous cyber analysts have none for their understanding. Current evaluations mostly score whether the agent solved the task, not how much of the target it actually understood.

The approach

TRACE builds that missing coverage measure and attaches it to every analyst run as an assurance receipt. It works in three steps that repeat:

  • Establish. Build a baseline of what there is to understand in a target: its interfaces, parsers, authority paths, and reachable exploit conditions. Lifting the target to higher-level representations exposes structure that ordinary tools miss; lifting protocol implementations to format specifications, for example, has surfaced vulnerabilities other methods did not.
  • Measure. Monitor the analyst while it works and map what it did onto the baseline. Every claim it makes is linked to the evidence behind it, and the parts of the baseline it never reached become visible as blind spots.
  • Enhance. Go after the blind spots adversarially to separate harmless gaps from real residual exploitability, fold the results back into the baseline, and run again.

TRACE also grades capability. It holds a task fixed and varies how much abstraction the environment hands the analyst, from ready-made tools down to raw debugging primitives. An analyst that still reaches the coverage target with less help ranks higher. The receipt then reports coverage, evidence, blind spots, a capability grade, and which target classes the analyst is suited for.

What exists today

  • A hook-and-monitor base for capturing what AI agents do during a run, from Serenitix's agent-operations platform.
  • Program-analysis components that run as code. The integrated assurance capability is not yet a product; the listing was submitted at TRL 3.

What an award delivers

These items are planned, not built:

  • Language lifters for one or two languages, taken end to end rather than spread thin.
  • An agent-monitoring framework that maps an analyst's activity onto the lifted baseline and links each claim to its evidence.
  • Receipt and accreditation components: coverage, blind spots, capability grade, and trust for a given analyst on a given target class.
  • A first end-to-end demonstration: one analyst, one ground-truthed target class, one receipt, as a repeatable pipeline.

Who it is for

Defense programs that want to qualify autonomous cyber-reasoning systems before fielding them, or compare human analysts and agents side by side on the same targets in cyber ranges. Commercial AI code-audit and vulnerability-analysis vendors who want to show customers what their tools covered and what they missed.

Related work

TRACE uses the same differential idea as Serenitix's VeriFlow work on authority regressions; see the SURE '26 paper. The point that lifting exposes vulnerabilities other tools miss draws on Shi et al., CCS 2023 (arXiv:2305.11781).

How to engage. TRACE is Awardable through DARPA ERIS (listing 7-26-3487). Awardable is a determination, not an award. If you are a program office or partner interested in qualifying autonomous cyber analysts, contact Serenitix.
